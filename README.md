# Oyin-B & Timi-B Wedding Celebration Website

Official celebration website for **Oyindamola Serah Oshadare** & **Busayo Timileyin Akomolede**.

**Hashtag**: `#OyinTimiLoveBound26`

---

## 💍 Features

- **Hero Showcase**: Rotating editorial portraits with fine-tuned portrait aspect ratios and lightbox zoom.
- **Meet The Couple**: Full bios, professional backgrounds, quotes, and social links.
- **Pre-Wedding Shoot & Portrait Gallery**: 
  - Complete 17 high-resolution pre-wedding shoot photos by PROMN FILMS.
  - Bespoke royal traditional and white ceremony attire portraits.
  - Interactive categorization (*All Moments*, *Editorial*, *Candid*, *Details*, *Heritage*).
  - Full-screen animated lightbox modal with keyboard and swipe support.
  - Direct link to the full high-res Pixieset gallery.
- **Gift & Donation Stationery**:
  - Interactive copy-to-clipboard cards for wedding gifts (First Bank & VFD Microfinance Bank).
- **Responsive & Botanical Accents**:
  - Styled with Tailwind CSS, custom fonts (*Playfair Display*, *Cormorant Garamond*), and delicate gold/olive accents.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
